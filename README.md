# 🚗 CaRent Dashboard

Application web de gestion de locations de véhicules avec chauffeurs.

## 🎯 Objectif
Faciliter la gestion des locations de véhicules (clients, chauffeurs, voitures) via une interface simple, moderne et responsive.

## ✨ Fonctionnalités
- Ajout, modification et suppression de locations
- Données persistantes (localStorage)
- Recherche instantanée
- Dashboard dynamique
- Interface responsive (desktop & mobile)
- Menu hamburger
- Confirmation avant suppression

## 🧱 Technologies utilisées
- HTML5
- CSS3 (Flexbox / Responsive)
- JavaScript (Vanilla)
- Font Awesome
- Git & GitHub
